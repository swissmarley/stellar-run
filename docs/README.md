# STELLAR RUN: run, build, test

Requirements: Node ≥ 22.18 (it runs the `.ts` tools natively) and npm. Nothing else is needed to play or build.

## Run

```bash
npm ci
npm run dev                     # http://localhost:5173/stellar-run/
```

**Play on a phone:** open the dev server's network URL (Vite prints it) on a device on the same Wi-Fi.
Tilt steering and installing as an app need HTTPS. The production site on GitHub Pages has it.

## Build

```bash
npm run build                   # static site in dist/ (gzip ≈ 280 KB, JS ≈ 195 KB)
npm run preview                 # serve dist/ at http://localhost:4173/stellar-run/
```

- **Hosting:** `dist/` is a self-contained PWA: manifest, service worker for offline play, CSP. Any static host
  works.
- **Base path:** `base` in `vite.config.ts` is set for `https://<user>.github.io/stellar-run/`. Change it to host
  elsewhere.
- **Deployment:** CI deploys to GitHub Pages on every push to `main` (`.github/workflows/ci.yml`).

**"iOS and Android builds".** The game is a web app by design (see DECISIONS #2).
- On iOS, open the site in Safari, then Share → Add to Home Screen.
- On Android, open it in Chrome and choose Install app.
- It then runs full-screen, in portrait, and offline.

The e2e suite runs the production build in Chromium (Android's engine) and WebKit (iOS's engine), on Pixel 7,
iPhone 15 and foldable viewports.

## Test

```bash
npm run lint                    # Biome + TypeScript (strict), must be clean
npm test                        # Vitest: 141 unit tests (~12 s)
npm run bot -- --runs 100 --seed 1    # 100 perfect-bot + 100 human-bot seeded runs (~4 s)
npm run test:e2e                # Playwright: Chromium + WebKit, 3 device profiles
npm run ci                      # all of the above + build, like CI
```

| Command | What it does |
|---|---|
| `npm run bench` | Performance bench on the production build: Chromium with GPU and WebKit. Writes `docs/perf/bench.json`; summarised in PERF.md. |
| `node --expose-gc --max-semi-space-size=64 tools/alloc-check.ts` | Allocation and GC behaviour of the tick path. |
| `node tools/gen-bench.ts` | Distribution of chunk-generation time. |
| `node tools/golden.ts` | Prints the generator golden hashes. Update `src/core/gen/golden.ts` after an intentional generation change. |
| `npm run docs:tuning` | Regenerates TUNING.md from `src/data`. |
| `npm run icons` | Regenerates the PWA icons. |
